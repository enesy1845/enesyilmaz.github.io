NOI AXIS REFINED / VERSION 04

This package contains the approved custom NOI wordmark as an installable mini-font and vector assets.

What this version does:
- Keeps the selected Axis-style n and o unchanged.
- Uses a taller i stem aligned with the shared x-height.
- Adds deeper inward scoops to the top and bottom of the i stem.
- Keeps the i dot perfectly round and separate in the SVG wordmark for possible later animation.

Coverage:
- n / o / i
- N / O / I (mapped to the same glyph forms)
- dotless ı
- space

Important:
- This is a bespoke display mini-font for the NOI wordmark, not a full alphabet.
- For hero/logo animation, prefer the SVG wordmark because the dot is a separate circle there.
